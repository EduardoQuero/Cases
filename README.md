# Portfólio de Dados | Eduardo Quero

Projetos práticos de análise de dados, modelagem preditiva e aplicações interativas desenvolvidos com **Python, SQL, Pandas, scikit-learn e Streamlit**.

O objetivo deste portfólio é demonstrar como transformo dados em análises reproduzíveis, visualizações claras e soluções que apoiam decisões.

## Projetos em destaque

| Projeto | Problema resolvido | Competências demonstradas |
|---|---|---|
| [Previsão de renda](https://github.com/EduardoQuero/previsao-renda) | Estimar renda com base em informações cadastrais | Python, Pandas, análise exploratória, regressão, Streamlit e CRISP-DM |
| [Classificação de risco de crédito](https://github.com/EduardoQuero/Credit-score) | Identificar características associadas à inadimplência | Tratamento de dados, visualização, classificação e interpretação |
| [Airbnb em Londres](./Análise_Dados_Airbnb_Londres) | Explorar preços, avaliações, localização e tipos de acomodação | Análise exploratória, estatística e comunicação de insights |

## O que este portfólio demonstra

- preparação, limpeza e validação de dados;
- análise exploratória orientada a perguntas de negócio;
- criação e avaliação de modelos de machine learning;
- desenvolvimento de aplicações de dados com Streamlit;
- documentação técnica e organização reproduzível;
- comunicação de resultados para públicos técnicos e de negócio.

## Como executar

```bash
git clone https://github.com/EduardoQuero/Cases.git
cd Cases
python -m venv .venv
```

Ative o ambiente virtual, acesse o diretório do projeto escolhido e siga o respectivo `README.md`.

Para executar os notebooks:

```bash
pip install jupyter pandas numpy matplotlib seaborn scikit-learn
jupyter notebook
```
